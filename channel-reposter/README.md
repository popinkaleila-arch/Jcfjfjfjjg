# Channel Reposter — автоперезалив контента между Telegram-каналами

Юзербот читает канал-источник и публикует посты в ваш канал без метки
«Forwarded from». Панель `@ZzzLV_bot` только управляет, сама ничего не постит.

## Что нужно

- Python 3.10+
- Токен панели от @BotFather
- `api_id` / `api_hash` с https://my.telegram.org/apps
- Юзербот-аккаунт: подписчик источника, админ назначения с правом публикации

## Панель

1. `/start` → **🔐 Вход юзербота**: api_id, api_hash, телефон, код, 2FA.
2. **📥 Источник** и **📤 Назначение** (`@username`, id, `t.me/c/…`, избранное).
3. **🔗 Старт-ссылка** или **📜 С начала**.
4. **✏️ Описание**, **⏱ Интервал**, **📦 Лимит**.
5. **🖊 Правка поста** — описание уже залитого поста: ссылка, пересланный пост,
   «последний» или номер из списка. «-» снимает подпись. Команда `/edit`.
6. **🧹 Чистый перелив** (по умолчанию только фото/видео).
7. **▶️ Старт**. До 16 окон, **▶️ Старт все**.

Сессия: `reposter_userbot.session`. Повторный код не нужен, пока сессия жива.

`FLOOD_WAIT` на `auth.SendCode` нельзя обойти. Бот показывает оставшееся время
и не крутит повторные запросы кода сам.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN, по желанию ADMIN_IDS
python main.py
```

systemd: `deploy/channel-reposter.service`, ставится `deploy/install.sh`.
